ADDITIONAL TIPS FOR AI GENERATION
========================================

MIDJOURNEY:
- Add "--ar 16:9" ya "--ar 2.4:1" for wide banners
- Add "--v 5" ya "--v 6" for latest version
- Add "--quality 2" for higher quality
- Add "--no text, logos, brands, watermarks" to prevent unwanted elements

DALL-E / CHATGPT:
- Remove "--ar" aur "--v" parameters
- Add "Wide banner format, 1920x800 pixels"
- Add explicit instruction: "Do not include any brand names, logos, or trademarks except where specified"

STABLE DIFFUSION:
- Add "masterpiece, best quality, ultra-detailed"
- Use negative prompts: "low quality, blurry, pixelated, text, logos, brand names, watermarks, trademarks"

EXTRA BRAND PROTECTION TIPS:
- Agar AI tool se unwanted text/brands aa rahe hain, to prompt ke end me ye add karein:
  "Negative prompt: text, words, letters, logos, brand names, watermarks, signatures"
- Midjourney me "--no text,words,letters,logos,brands,watermarks" use karein
- Result check karein aur agar koi unwanted brand name ho, to regenerate karein
